# LMS 데모

영어학원 LMS 제안용 화면 프로토타입. 단일 HTML 파일로 동작하며 서버가 필요 없습니다.

## 화면

- 대시보드: 오늘 처리할 일, 파이프라인 처리 상태
- 접수 관리: 상담·입학테스트 신청 상태 진행
- 진단서: 영역별 성취와 AI 해설
- 반 배정: 권장 반 표시 후 대표 확정
- 출석부: 회차 커리큘럼이 반영된 출결 입력
- 숙제 배포·회수
- 레벨테스트 응시: 응시 후 자동채점 결과
- 학부모 리포트: 알림톡 링크 열람 화면, 인쇄 가능
- 상담 신청·커리큘럼 안내

상단 역할 선택으로 운영자·상담실장·강사·학생·학부모 화면을 전환할 수 있습니다. URL 해시(#report-view 등)로 특정 화면을 바로 열 수 있습니다.

샘플 데이터만 사용하며 실제 서비스가 아닙니다.
